# 管理后台设计

## 目标

- 独立构建、独立部署，可按需启用。
- 通过同源 `/api/` 代理访问服务端，不在浏览器暴露内部服务地址。
- 管理操作统一、直接，危险操作必须确认。

## 技术方案

- 使用 Vue 3、Vue Router 与 TypeScript。
- UI 统一使用 PrimeVue 4.5.5，采用 Aura 主题与设计令牌。
- 表格、分页、多选、侧栏、表单控件、确认框和消息提示均使用 PrimeVue 官方组件。
- 布局间距使用 PrimeFlex，仅保留应用外壳所需的少量结构样式。
- 不使用渐变、装饰性背景和自定义组件皮肤。

## 信息架构

| 分组 | 页面 | 路径 |
| --- | --- | --- |
| 数据概览 | 总览 | `/admin/` |
| 运营管理 | 对局列表、对局详情、房间、用户 | `/admin/matches`、`/admin/matches/:id`、`/admin/rooms`、`/admin/users` |
| 素材管理 | 角色、桌布、音乐 | `/admin/characters`、`/admin/tablecloths`、`/admin/music` |
| 系统管理 | 数据库、审计日志 | `/admin/database`、`/admin/audit` |

角色、桌布、音乐新增页分别使用 `/new`；编辑页使用 `/:id/edit`。

## 页面规范

- 参考 PrimeVue Sakai 的静态导航结构：桌面端使用全高固定 `Menu`，账户操作放在侧栏底部；窄屏使用紧凑工具栏与 `Drawer`。
- 桌面端不设置全局顶部栏，减少无效纵向占用。
- 内容区使用浅灰背景、白色内容面板、细边框和轻量阴影建立层次；加载遮罩保持白色，不使用深色闪屏。
- 页面标题只描述当前对象，不使用说明性长文案。
- 列表页由筛选栏、批量工具栏、分页表格组成。
- 表格首列为复选框，末列为操作；危险操作使用二次确认。
- 角色、桌布、音乐支持多选导出和 JSON 导入，格式见[素材导入导出](import-export.md)。
- 表单按基础信息、资源信息、状态设置分组；底部仅保留取消、保存。
- 默认色为墨绿色 `#176B55`，背景 `#F4F6F5`，无渐变、无装饰性插画。
- 状态只使用中性色、绿色、橙色、红色；正文和按钮使用简短中文。

## 响应式与可访问性

- 表格在窄屏横向滚动，关键列固定。
- 图标按钮提供中文辅助标签。
- 所有输入项均有可见标签；错误显示在对应字段或页面顶部。
- 键盘可完成导航、筛选、分页、保存和确认操作。
