# 素材导入导出

角色、桌布、音乐列表支持多选导出和 JSON 导入。导入使用现有新增、编辑接口，不增加独立服务端接口。

## 文件格式

```json
{
  "schema": "admin_asset_bundle.v1",
  "kind": "characters",
  "exported_at": "2026-08-11T00:00:00.000Z",
  "items": []
}
```

`kind` 仅允许 `characters`、`tablecloths`、`music`。`items` 使用对应新增接口的请求结构，不包含数据库版本号。

## 导入规则

- 仅接受单个 JSON 文件，文件上限 5 MB。
- `schema`、`kind` 和所有必填字段必须正确。
- 编号已存在时调用编辑接口，否则调用新增接口。
- 按文件顺序逐项处理；任一请求失败时停止，保留此前已成功的数据。
- 导入完成后刷新列表；危险覆盖沿用管理端审计记录。
