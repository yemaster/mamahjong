# ADR-0009：可玩版使用原子 JSON 战绩归档

状态：已接受，后续迁移
日期：2026-07-31

## 背景

可玩版需要立即留存每局和整场记录，但 PostgreSQL 事务事件库属于后续基础
设施里程碑。

## 决策

服务端在开局、每局结算和整场结束时生成 `match_record.v1` 累积记录，并用
临时文件、`fsync`、同目录原子替换写入每场一个 JSON 文件。Docker 将归档
目录挂载到命名卷。

记录包含：

- 不可变规则快照和固定玩家座次、昵称；
- 每局场况、结束原因、点数前后、点数变化、和牌与听牌座位；
- 每局事件序号范围；
- 整场结束原因、最终点数、顺位、马点和 Oka 结果。

普通出牌不触发写盘。文件归档属于基础设施层，领域层只生成确定性记录投影。

## 迁移

JSON schema 保持版本号。接入 PostgreSQL 后，以同一记录投影回填
`hand_records` 和 `match_results`，再把完整领域事件写入追加事件表。JSON
归档不替代目标数据库的命令幂等、事件事务和运行中牌局恢复能力。
