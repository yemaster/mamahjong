# ADR-0008：客户端以协议与服务端分离

状态：已接受
日期：2026-07-31

## 决策

服务端和客户端只通过版本化 HTTP/WebSocket 协议交互。客户端不得依赖服务端
应用层、领域层或日麻规则 crate，也不共享进程内领域对象。

当前终端客户端独立维护协议 DTO，只依赖 HTTP、JSON 和 TUI 库。后续网页端
可使用 TypeScript，原生应用可使用 Kotlin、Swift 或其他合适语言。需要代码
生成时，以 OpenAPI/JSON Schema 为输入，不从 Rust 领域类型生成客户端模型。

客户端只提交用户意图。动作合法性、隐藏信息、和牌判定和计分始终由服务端
决定。

## 结果

- 服务端规则实现可独立演进；
- 不同平台可选择各自合适的语言和界面架构；
- 协议兼容性必须通过契约测试维护；
- 客户端需要单独的会话状态、观察者模型和本地化文案层。
