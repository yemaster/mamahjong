# ADR-0010：副露规则组与规则快照 schema 2

状态：采纳
日期：2026-07-31

## 背景

路线图要求的两项规则尚未建模：

- 食断：副露后断幺九是否成立；
- 食替：吃碰之后能否打出与被鸣牌同一牌或其筋牌。

食替判定已经硬编码在单局状态机中，始终禁止现物与筋；食断则完全缺失。两者
都不属于既有的计分、宝牌、流局或结算分组：它们描述的是「副露带来的限制」。

配置结构一旦增加必填字段，旧快照 JSON 就不能再反序列化。按 ADR-0005，快照
是牌局的权威规则来源，读取时必须重新校验，不能猜测缺失字段。

## 决定

新增配置分组 `calls`：

```text
calls
├── kuitan  bool
└── kuikae  forbidden / same_tile_only / allowed
```

`RiichiRuleSnapshot` 的 `schema_version` 由 1 提升为 2，读取器只接受 2。

不提供 1 到 2 的自动迁移：当前不存在持久化快照，仓库内的固定样例随本次
变更一并更新。若将来出现线上数据，迁移由持久化层显式实现，不在读取器中
默认补齐字段。

## 后果

- 食替由规则驱动，状态机不再隐含固定策略；
- 食断关闭时，副露纯断幺九手牌因为无役而不能和牌，无需额外判定分支；
- 所有预设显式声明 `calls`，不依赖普通默认值；
- 任何持有 schema 1 快照的外部数据必须先迁移再读取；
- 后续副露相关规则（大明杠责任、包牌）有明确归属分组。
