# ADR-0007：纯计分器与结算分层

状态：采纳
日期：2026-07-30

## 背景

和牌存在多种合法拆分，最高翻不一定等于最高实际得点。状态机还需要频繁
询问听牌、和牌和立直后暗杠，但不能把搜索、役判断和点数移动混在动作代码中。

## 决定

- 使用无状态 `RiichiScorer` 完成牌形、役、符番和基本支付计算；
- 固定 34 牌种计数作为搜索表示，枚举全部合法拆分和和牌张解释；
- `HandJudge` 由同一计分内核实现，合法动作与最终计分不使用两套算法；
- `HandSettlement` 只消费已验证的计分结果，生成点数变化、供托转移与下一局
  进度，并保持玩家点数加供托总量守恒；
- `MatchResult` 独立计算顺位、Oka 和马点，不污染单局牌型算法；
- 结果对象不可变并保存组成明细，持久化层不重新计算历史得分。

## 后果

- 多义牌形能够稳定选择实际得点最高方案；
- 可独立测试搜索、役、符、支付、连庄和终局；
- 新玩法可以替换计分与结算实现，不复用日麻 34 牌种假设；
- 增加役或三麻支付变体时必须修改规则版本或显式配置；
- M5 应用层只负责编排和持久化，不自行增减点数。
