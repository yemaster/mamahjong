# ADR-0003：规则引擎拥有玩法状态

状态：采纳  
日期：2026-07-29

## 背景

日麻四人、三人共享大量概念，但川麻、武汉麻将和特殊规则的牌集合、动作、
结算乃至一局生命周期都可能不同。把全部玩法放进一个通用大对象会产生持续
增长的条件分支。

## 决定

公共游戏层只管理玩家身份、桌局版本、命令幂等、事件顺序和引擎注册。
每个规则引擎拥有自己的配置、牌表示、局状态、动作和计分。公共层通过
`RuleSetId + engine_version` 选择引擎，规则快照保存解析后的完整配置。

外部使用稳定字符串编码；引擎内部可以采用面向性能的紧凑表示。

## 后果

- 新玩法不需要修改日麻内部类型；
- 四人/三人日麻仍可复用同一个日麻基础模块；
- 跨玩法的 UI 需要读取引擎元数据和配置描述；
- 引擎适配层必须负责类型擦除、快照迁移和网络投影。
