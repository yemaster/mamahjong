# ADR-0006：单写权威状态机与判定器边界

状态：采纳
日期：2026-07-30

## 背景

一张弃牌可能同时产生多家的荣和、碰、杠或吃请求。网络消息到达顺序不能
决定规则结果，和牌与听牌算法又将在 M4 独立实现。

## 决定

- 每局由一个 `RiichiHand` 聚合和一个串行执行者负责写入；
- 弃牌及抢杠使用显式响应窗口，收齐合法响应后按规则优先级解析；
- 超时由应用层转换成普通 `Pass`，状态机不依赖系统时钟；
- 状态机拥有牌和阶段，M4 通过只读 `HandJudge` 提供和牌、听牌、立直与
  立直后杠判定；
- 状态转换产生内部领域事件，网络层再按观察者投影；
- 无效命令在任何状态修改前完成校验，不通过复制整个聚合实现回滚。

## 后果

- 消息延迟和线程调度不会改变牌局结果；
- M3 可以用确定性测试判定器完整测试流程，M4 接入时不改命令协议；
- 应用层必须为响应窗口安排超时并提交 `Pass`；
- 事件不能直接广播，必须裁剪隐藏信息；
- 状态机实现需要明确区分判定、修改和自动推进步骤。
