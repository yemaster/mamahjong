# ADR-0005：完整且版本化的规则快照

状态：采纳
日期：2026-07-30

## 背景

房主需要组合大量规则，官方预设也会随时间变化。如果牌局只保存预设名称或
依赖服务器当前默认值，历史复盘和故障恢复可能得到不同结果。

## 决定

房间接受 `preset + overrides`，应用层将其解析为完整、严格校验的
`RiichiRules`。开局保存：

- 快照 schema 版本；
- `RuleSetId`；
- 规则引擎版本；
- 可选预设 ID 与修订号；
- 所有默认值已经展开的完整配置。

预设更新只能增加修订号。计分和状态机只读取完整配置，不读取预设名称。

## 后果

- 历史牌局不受默认规则更新影响；
- 客户端可以准确展示实际生效规则；
- 配置 JSON 需要兼容读取器和迁移测试；
- 覆盖项必须采用严格字段白名单，不能任意合并 JSON；
- 官方规则未被当前模型覆盖的部分必须明确说明，不能暗示完整等价。
