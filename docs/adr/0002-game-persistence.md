# ADR-0002：追加事件与周期快照

状态：采纳  
日期：2026-07-29

## 背景

在线麻将需要断线恢复、故障恢复、战绩复盘、争议审计和反作弊。只保存最终
状态无法解释过程；只依赖事件重放会让长对局恢复变慢，并受旧引擎代码影响。

## 决定

权威存储采用按桌有序的追加事件，同时周期性保存带引擎版本的完整快照。
恢复时加载最近快照并应用其后的事件。事件和快照格式都独立版本化。

内部领域事件与外部网络事件分离。隐藏状态进入加密 payload 或加密快照，
网络层只发布针对观察者生成的投影。

## 后果

- 可以恢复、审计和生成复盘；
- 快照控制恢复时间；
- 存储和迁移实现比“只存当前状态”复杂；
- 必须维护历史事件读取器和引擎版本；
- 必须对密钥、隐藏信息访问和数据保留建立运维流程。
