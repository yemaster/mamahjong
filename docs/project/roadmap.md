- [x] 初始化 Git 和 Rust workspace

- [x] 设计对象模型、存储格式和通信协议

## M1 日麻基础模型

- [x] 完成 M1 对象、随机性与牌山分区设计
- [x] 牌、牌种和赤牌值对象

## M2 规则配置

- [x] 完成配置、校验、预设和快照 JSON 设计
- [x] 全部布尔/枚举/数值规则字段

## M5 房间后端与实时传输

- [x] 用户注册、昵称、会话及可扩展档案
- [x] 称号、段位和使用角色的目录/关联预留
- [x] 建房、配置、加入和准备
- [x] HTTP 观察者视图、版本化命令和串行执行

## 不再维护

控制台客户端（`clients/console`）不再维护。后续客户端开发集中在
`apps/game-web`（网页）和 `apps/desktop`（桌面）。

## 实施纪律

- 先更新设计文档，再实现对应模块。
- 每个勾选项使用独立提交；不在同一提交混入下一阶段功能。
- 公开协议或存储格式发生破坏性修改时，必须先增加 ADR 和迁移方案。
- 路线图中的后续项允许细化，不允许绕过当前里程碑的不变量测试。
- 每阶段结束运行格式化、Clippy、全工作区测试与前端类型检查。
