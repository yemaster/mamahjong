# 冲击麻将规则与配置

状态：已实现（仅好友房，四人）
最后更新：2026-08-13

冲击麻将是仓库里的第二套规则集，引擎在 `crates/mahjong-impact`，
与日麻引擎完全隔离。接入方式与已知缺口见
[ADR-0011](../adr/0011-second-rule-family-impact.md)。

`RuleSetId` 为 `impact/yonma`，座位数固定 4。**只能通过好友房开局**：
匹配队列显式拒绝 `impact/*`，也不接入段位与机器人。

## 玩法

### 和牌

- **瞎子麻将**：只有自摸，不能吃、荣和或抢杠；别人打出的牌只能碰或明杠。
- **亮子麻将**：可以吃、荣和与抢杠，并使用同巡振听。每位玩家从另外每一家的
  舍牌形成副露最多 2 次，吃、碰、明杠合并计数。
- 牌型四种：
  1. 标准型 3+3+3+3+2（三张一组可以是顺子或刻子——不能吃，但暗顺合法）；
  2. **七对子**，遵循「一杠一达，二杠二达」：一个杠顶两个对子，因此
     1 杠 + 5 对 + 任意 1 张（15 张）、2 杠 + 3 对 + 任意 2 张（16 张）
     都成立；
  3. **十三不搭**：全手无对子，且任意两张同花色数牌相差 **大于 2**；
  4. **七嵌**（`special.seven_gaps` 打开时）：7 组，每组是同花色、
     相差 **恰好为 2** 的两张数牌。

### 财神

翻开的那张是**财神指示牌**，它的**下一张**才是财神：

| 类别 | 循环 |
|---|---|
| 数牌 | 1 → 2 → … → 9 → 1（同花色） |
| 风牌 | 东 → 南 → 西 → 北 → 东 |
| 三元 | 中 → 发 → 白 → 中 |

财神是百搭，可以当任意一张牌用，**十三不搭与七嵌里同样适用**。
但**财神本身不能被碰、被杠**：它只在和牌时顶替别的牌，不进副露。打出来的
财神谁也鸣不了，手上四张财神走「四龙全交」而不是暗杠。
前端理牌时把财神提到手牌最左并单独高亮。

### 牌山与开门

1. 庄家掷两颗骰子，`sum = d1 + d2`；从庄家数 1、**逆时针**数到 `sum`，
   数到谁那一面就从那面开门。
2. 开门那一面从左起先留出 `min(d1, d2)` 墩，从下一墩开始摸。
3. 翻财神的是**开门位的下家**：数自己面前那 17 墩，从左往右数到第 `sum` 墩，
   把那一墩的**上层牌**翻开作财神指示牌。
4. 翻财神那一墩**整墩不摸**——翻开的指示牌和它下面那张都留在山上，
   可摸的是余下 **134 张**。
5. 杠张从牌山**最末尾**取。
6. 摸完无人和牌 → 本局不算，**同一个庄家直接重开**。

### 点数与杠点

- 每人起始 **100 点**，杠点 **0**。没有场风自风，没有立直。
- 自摸时，和牌者向其余三家各收取整份点数。亮子麻将荣和时，放铳者支付整份点数，
  另外两家各支付一半（向上取整）。某家不足时把手上剩余点数全部给和牌者，
  **本节到此结束**。点数下限 0，不会为负。
- 亮子麻将抢杠时，加杠者独自支付 3 倍和牌点数，并向另外三家各支付 1 杠点；
  加杠不成立，其他玩家不支付点数。
- **全交**：和牌者变成 **400 点**，其余三家全部归零。
- **任何一家点数归零 → 整场立即结束**，进入结算，逐人列出点数增减与杠点。
- 庄家和牌则**连庄**；闲家和牌则庄家轮转、连庄清零。

杠点是与点数分开的一本账，**可以为负，不设下限**，也不参与「点数归零」判定：

| 情形 | 支付 |
|---|---|
| 明杠 | 被杠那家付 3 给杠者 |
| 暗杠 | 其余三家各付 2 |
| 加杠（`added_kan_single_payer = false`） | 其余三家各付 1 |
| 加杠（`added_kan_single_payer = true`） | 只有被碰走那张牌的那家付 3 |
| 指示牌碰 | 按明杠结算（被碰那家付 3） |
| 指示牌暗杠 | 按暗杠结算（其余三家各付 2） |
| 第一巡连打 | 庄家向其余三家各付 1 |

- **指示牌碰 / 指示牌暗杠** 只结算杠点：牌型仍算**刻子**，
  不摸岭上牌、不算杠上开花，**也不计入三杠**。需要
  `indicator_pon_counts_as_kan` 打开。
- **第一巡连打**：庄家打出第一张后，三家无人鸣牌且依次打出**同一种牌**，
  庄家向其余三家各付 1 杠点，牌局继续。需要
  `first_round_repeat_discard` 打开。

### 算点

底和 **12**，下列番种在其之上累加：

| 番种 | 点 |
|---|---|
| 无财神 | +1 |
| 两财神 | +1 |
| 三财神 | +2 |
| 七对子 | +1 |
| 七嵌 | +1 |
| 对对和 | +1 |
| 十三不搭 | +1 |
| 七风齐 | +1 |
| 清一色 | +10 |
| 抛龙 | +10 |
| 杠上开花 | +10 |
| 单吊 | +10 |
| 连庄 | +10 × 连庄次数 |

- **七风齐**：十三不搭里东南西北中发白恰好各一张（财神不计）。
- **清一色**：有财神且财神当了别的牌。若无财神、或财神没当别的牌，
  走「无龙清一色」全交分支。
- **抛龙**：3+3+3+3 或 2+2+2+2+2+2 已经做完，多一张财神单钓将，
  摸任意一张牌都能和。
- **抛龙与杠上开花**：只有在**一杠一达、二杠二达凑出来的七对子**上互斥——
  那张「任意牌」就是杠完摸上来的岭上牌，两条说的是同一张，只算杠上开花。
  其余牌型两条可以同时算，例如 `1s2s3s 4s5s6s 7s7s7s 8s8s8s + 财神` 杠掉 7s，
  抛龙靠的是单钓的那张财神，与岭上牌无关。
- **单吊**：四组副露或杠已经摆出，手上只剩一张牌钓将。
- **连庄** 无论那是谁的连庄都算。

### 全交

| 开关 | 触发 |
|---|---|
| `eleven_honor_streak` | 同一家**连续**打出 11 张字牌或财神（被他家鸣牌不打断，但必须是自己连着打出来的） |
| `all_honors` | 全风：整副手牌只有字牌（财神可当字牌） |
| `pure_flush_no_joker` | 无龙清一色：清一色且无财神、或财神没当别的牌 |
| `single_wait` | 单吊 |
| `three_kans` | 一局内做出 3 个杠（指示牌碰/指示牌暗杠不计） |
| `four_jokers` | 四张财神在手，立即和牌（财神不能被杠，所以只可能是手里四张） |
| `pure_seven_pairs` | 清七对：手里恰好七对（**有杠就不算**），且无财神、或财神没当别的牌 |
| `last_tile` | 海底：摸牌山最后一张自摸 |
| `blessing` | 天和（庄家起手即和）/ 地和（闲家第一次摸牌即和） |

牌型类全交（全风、无龙清一色、单吊、清七对、海底、天和地和）
在开关关闭时改记 **+10 点**；触发器类（连打十一风、三杠）关闭后
就不存在这条路径。

## 配置结构

```text
ImpactRules
├── mode                              // blind（瞎子麻将）/ bright（亮子麻将）
├── match_rules
│   └── thinking_time
│       ├── base_seconds
│       └── reserve_seconds
├── kan
│   ├── added_kan_single_payer        // 加杠时仅单人支付        默认 true
│   ├── indicator_pon_counts_as_kan   // 指示牌碰牌算杠          默认 true
│   ├── first_round_repeat_discard    // 第一巡连打需庄家支付杠点 默认 true
│   ├── four_identical_discards_as_kan// 打出四张相同牌算杠      默认 true
│   └── pon_with_few_tiles_as_kan     // 手牌≤4张时碰牌收杠点    默认 true
├── special
│   └── seven_gaps                    // 七嵌                    默认 false
└── all_in                            // 九项，默认全部 true
    ├── eleven_honor_streak
    ├── all_honors
    ├── pure_flush_no_joker
    ├── single_wait
    ├── three_kans
    ├── four_jokers
    ├── pure_seven_pairs
    ├── last_tile
    └── blessing
```

`thinking_time` 与日麻用同一组取值：`(5, 0)`、`(5, 20)`、`(5, 60)`、
`(15, 60)`，其余组合拒绝。

建房页选择 `bright` 时，五项 `kan` 附加设置默认全部关闭；`all_in` 默认只开启
`eleven_honor_streak`、`four_jokers`、`blessing`。切回 `blind` 时恢复五项
杠牌设置与九项全交全部开启的原有默认。

与日麻一致，房间接受 `preset + overrides`，`overrides` 的每一层都是
`deny_unknown_fields`（见 [ADR-0005](../adr/0005-versioned-rule-config.md)）。
`overrides` 只接受上面这五组字段——把日麻那几组（`scoring` / `calls` /
`bonuses` / `abortive_draws` / `settlement`）发过来会整份被拒。

## 协议投影

`match_view.v1` 不按规则集分裂 schema。冲击麻将独有的字段一律可选，
日麻路径下不序列化：

| 字段 | 语义 |
|---|---|
| `variant_kind` | `"riichi"` / `"impact"`，客户端的分支依据（恒有） |
| `joker_indicator` / `joker_code` | 财神指示牌与推出来的财神牌码 |
| `dealer_streak` | 连庄次数 |
| `players[].kan_points` | 该家当前杠点 |
| `last_kan` | 最近一次杠点变动 `{ id, seat, kind, deltas }` |
| `hand_settlement.all_in` | 触发的全交种类；非空时番种表只列这一条 |
| `hand_settlement.kan_point_deltas` / `kan_points_after` | 本局杠点增减与结果 |

`last_kan.id` 整局单调递增，客户端靠它区分「新的一次杠」与「同一次的重发」。
`kind` 取值：`open_kan` / `concealed_kan` / `added_kan` / `indicator_pon` /
`indicator_concealed` / `first_round_repeat_discard`。

副露 `kind` 增加 `indicator_pon` / `indicator_concealed` 两种。

## 已知缺口

- **不生成牌谱记录，因此没有牌谱重演。**
- **不产生事件流**（`event_sequence` 恒为 0）。game-web 走视图模式不受影响，
  依赖事件流的终端客户端看不到冲击麻将对局。
- 不接入匹配队列、段位与机器人。
